# Project Compass

我要一个项目管理的软件，涵盖产品线，产品线里的产品名称，硬件进度，app进度，ai进度，预期试产时间，预期量产时间，正式发售时间等，方便各个业务线可以知道各自的进度

This project was built with [Lovable](https://lovable.dev).

**Live app**: https://vision-voyage-tracker.lovable.app
